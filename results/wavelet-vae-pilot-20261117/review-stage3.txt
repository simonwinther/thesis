After a resume the file covers only the resumed part (`train.py:125`), which does not matter if the pilot is not resumed.
2. **`deterministic` in the JSON means "trained with z = mu"** (`train.py:86`): true for overfit, false for pilot. It says nothing about cuDNN determinism, so label it that way in the write-up.
