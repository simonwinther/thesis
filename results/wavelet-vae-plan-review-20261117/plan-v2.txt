Wavelet VAE reconstruction pilot: revised implementation plan
Date: 2026-11-17. Proposal only: implementation, installation, syncing and training have not started.

Purpose
Test whether the proposed LF/HF compression preserves MRI anatomy and detail before adapting WFM. Reconstruct observed scans; this is not missing-modality synthesis. Use one configuration and seed43. This adopts DeBaT's LF/HF split but not its full training recipe. Existing WFM/WMF implementations, datasets and experiment outputs stay separate.

1. Architecture and data
Keep the current BraTS 2023 GLI split (1,251 training / 219 validation cases), four modalities, percentile normalization and pad/crop to224x224x160. Train the same LF/HF model pair across all four modalities, sampling one complete scan at a time. Load only the selected modality; check the saved split identities and patient separation.
Haar DWT gives eight bands at112x112x80. Preserve order LLL,LLH,LHL,LHH,HLL,HLH,HHL,HHH, LLL/3 before encoding and *3 before inverse DWT.
LF: 1x112x112x80 -> 2x28x28x20 -> 1x112x112x80.
HF: 7x112x112x80 -> 2x28x28x20 -> 7x112x112x80.
Concatenate the two latents into4x28x28x20; split for independent decoding. All wavelet outputs are unrestricted signed values. No sigmoid or coefficient clipping.
Total128x fewer scalars and64x fewer spatial positions than wavelet inputs. LF alone is32x smaller and HF224x smaller, so HF preservation is a key test. These are representation ratios, not measured runtime or disk-compression ratios.
Use two MONAI AutoencoderKL instances from a pinned verified release in a separate environment: spatial_dims=3, channels=(32,64,64), num_res_blocks=1, norm_num_groups=16, latent_channels=2. Disable attention at every level AND both encoder/decoder nonlocal attention. No pretrained weights. Verify constructor keywords for the pinned version before implementation; do not install over the baseline environment.

2. Minimal implementation
data.py: preprocessing/split handling and a fixed Haar adapter; model.py: common model factory; train.py: --band lf|hf; evaluate.py: metrics and plots; checks.py: direct invariant/smoke checks. One dependency file records versions. No new framework or job distributor.
The preferred simple adapter is PyWavelets Haar on CPU for input preprocessing and evaluation-only inverse DWT. No gradients through DWT/IDWT are needed because training loss is on wavelet coefficients. Confirm per-band coefficients (including signs/order/boundaries) and inverse match the existing implementation on non-cubic tensors and actual scans before adopting it; do not assume API ordering. Baseline reference CPU checks must hide CUDA because its implementation chooses CUDA globally. If equivalence fails, resolve it before training rather than silently changing transform conventions. No full-dataset wavelet cache in this pilot.
One branch per process/GPU. Use existing host submission conventions and record GPU, versions, config, seed, data manifests and code hashes. Mostafa remains capped at2 concurrent GPU jobs. Local changes first; code-only rsync later, when execution is authorized.

3. Training objective and deterministic evaluation
Per branch: mean squared coefficient reconstruction error + beta * KL_mean, initial beta1e-6, with both means explicitly defined over all respective tensor elements. KL_mean=mean(0.5*(mu^2+variance-1-log(variance))). Initial implementation uses float32 for simplicity. Adam lr1e-4, batch1, fixed lr, balanced modality sampling.
This is an explicitly weak KL starting point, not a value borrowed unaltered from a sum-reduced tutorial; no claim that it guarantees a standard-normal latent distribution. Log reconstruction, raw and weighted KL, and per-channel mu mean/std and mean posterior std. No silent loss or beta adjustment.
Training samples z=mu+sigma*epsilon. MONAI encode returns mu and sigma (standard deviation, not variance/logvar). Use its clamping convention and compute the loss consistently from sigma or the equivalent clamped logvar.
Evaluation must call encode then decode(mu); eval() alone does not disable sampling in forward()/encode_stage_2_inputs(). Cached latents would follow that same mean policy later, after approval. Mean decoding is not the expected decoded image. No latent-WFM compatibility or quality guarantee follows from this pilot.

4. Bounded checks and training proposal
A. CPU correctness checks: DWT/IDWT round trip and baseline coefficient equivalence, full-size shape expectations, concat/split identity, finite gradients through both VAE encoder/decoder, finite positive posterior std and KL. Verify[1,2,28,28,20] per branch on a full-size GPU pass. Test the actual non-cubic geometry; float32 round-trip error target1e-5 for normalized input.
B. Time50 warmed-up updates per branch INCLUDING data loading and record peak VRAM. No fixed speed or completion-time promise before this measurement. This times VAE training only; WFM speed is measured later in its own controlled comparison.
C. Proposed initial training budget: at most2 GPU-hours per branch, including warmup/debug and main pilot, plus separately measured validation time. Two branches are at most4 GPU-hours of training; parallel execution may reduce wall time if two GPUs are available. Report estimated updates/epoch coverage from actual speed before launch of the longer portion; one full scan epoch has5,004 examples. The budget is a proposal, not an authorization to submit now.
D. Debug overfit on four fixed training scans, one modality each from distinct patients. Use beta0 and deterministic z=mu only for this isolated diagnostic. Stop after clear convergence or at most20 minutes per branch within the budget. Monitor absolute reconstruction and HF error relative to a zero-HF prediction. Discard these weights. This tests implementation/optimization and gives an optimistic capacity probe; failure is not proof of an architectural limit. If it fails to learn useful detail, pause to diagnose rather than automatically start the main pilot or change channels.
E. Restart from fresh seed43 weights with the stated VAE objective on the training split. Use the remaining measured budget, with a recorded update cap derived from throughput. Save checkpoints and evaluate a fixed manifest of8 validation patients/all4 modalities at a few predetermined points (roughly every500 updates when feasible). Save the final checkpoint for each branch and compare named checkpoints with their actual update counts and GPU times; never silently call a shorter run converged. Different LF/HF speeds can yield different update counts under the same budget and must be reported, not hidden.
At the cap: a good result supports proceeding; poor results, especially with improving curves, are inconclusive about maximum achievable quality. No automatic extra training or sweeps. Keep a resume-capable checkpoint for a later explicit decision.

5. Reconstruction report and cheap controls
First report on the fixed8 development patients. If promising, freeze the selected pair and evaluate all219 validation cases/all4 modalities once for reporting. The8 are part of validation, so full219 results are validation, not a new untouched test. Do not use full219 scores to choose beta/checkpoints repeatedly.
Four evaluation rows, with no additional models/training: (a) DWT->IDWT identity; (b) original LF+zero HF; (c) reconstructed LF+zero HF; (d) reconstructed LF+reconstructed HF.
Compare(c) vs(d) to isolate the HF model's benefit at the SAME LF reconstruction, and(b) vs(c) to see LF reconstruction cost. Original-LF+zero-HF is a diagnostic, not a fair compressed competitor.
Use original normalized MRI and mask target>0, crop depth160 back to155, fixed data_range1. Brain-masked SSIM (full spatial map averaged in mask), PSNR, MAE/MSE. Raw reconstruction is the primary diagnostic: no re-normalization, clipping or NaN replacement. Fail/report nonfinite outputs. Verify against compute_metrics_masked. The legacy file-loading evaluator clips negative values; raw VAE scores must be labelled accordingly and not described as exactly identical postprocessing to every historical result. A matched clipped comparison can be explicitly reported later if needed; never alter HF coefficients or hide raw errors.
On8 patients: per-modality mean and lowest SSIM/PSNR, full-precision per-case values, and equal-modality macro mean. On full219: also descriptive sample SD, median and10th-percentile SSIM per modality and distributions. Case SD is not uncertainty across seeds. Existing WFM synthesis scores are context only, not a formal reconstruction cutoff/ceiling.
Detail diagnostics: raw (undo LLL/3) coefficient MSE and relative squared error sum((C_hat-C)^2)/sum(C^2), per band and combined HF, globally AND on interior coefficient positions whose2x2x2 block is entirely inside the original brain mask. Report zero-energy/empty-mask results as undefined. The zero-HF prediction has relative error1 for nonzero HF energy; check that learned HF beats it and that no band silently collapses. Boundary energy can hide interior losses; do not assert that this dataset is dominated by boundaries without measuring it.

6. Small, reproducible visual output
Quick report: training/reconstruction/KL curves; a compact per-modality metric table; one figure per modality with a fixed, named development patient and predetermined axial slice/zoom, showing original, reconstruction and absolute-error map with shared display ranges. Include original-vs-reconstructed HF-only images IDWT(0,HF) on a shared symmetric range to show smoothing/collapse. Record patient and slice selection. A fixed small set is an illustration, not coverage of all anatomy.
For the full report only, add per-modality SSIM/PSNR distributions and the lowest-SSIM case panels, explicitly labelled as worst cases. No interactive dashboard, generated-volume dump, or lesion-specific claims.
Save metrics, summaries, plots, provenance and timings; pull only size-checked lightweight files locally. Checkpoints remain on the training host unless a backup is explicitly requested. No full latent cache yet.

7. Decision
Discuss actual reconstruction/detail metrics, images, curve convergence and measured costs. Promising anatomy and HF preservation justify planning a small latent-WFM trial. Detail loss triggers diagnosis of implementation, optimization/time and bottleneck capacity, not an automatic model replacement. Any continuation, channel/beta change, latent cache or WFM integration is a separate next step. Reconstruction tests do not prove clinical fidelity, a mathematical synthesis-quality ceiling, or an end-to-end speedup.
