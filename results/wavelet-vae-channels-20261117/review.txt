1. **Same seed is not the same initialisation.** The encoder's last conv changes size with the width, so the random stream diverges after it (`train.py:75,96`). Decoder and quant-conv initial weights therefore differ between C2, C4 and C8. With one seed per width, list this next to the GPU caveat.

2. **The matched C2 report at 2500 does not exist yet.** `debug-report-final` used LF 3352 and HF 2656. For `--subset debug`, step equality is not enforced (`evaluate.py:198`), so passing `step-002500.pt` for both bands is up to the caller. The re-evaluation must use a manifest byte-identical to the pilot's (`evaluate.py:110`); a wrong one fails loudly.

3. **Scan identity across clusters rests on case IDs only.** Manifests store paths, not content hashes (`data.py:81`). A free check: the `target_energy` rows in each run's `validation-000000.json` (`train.py:121`) depend only on the data and should match the pilot's across C4 and C8. Compare `runtime.json` versions (`train.py:93`) at the same time.

4. **Widths 4 and 8 are not covered by `checks.py` itself.** `checks.py:125` still calls `check_models()` with the default. Only `results/wavelet-vae-channels-20261117/check_channels.py:15-16` exercises 4 and 8, and no output from it is saved in the evidence directory.
