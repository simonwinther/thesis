# notes/

Shared memory between agents and the user: what we're doing, why, and what's running.

- `HANDOFF.md`: current state. Read first, update when it changes. Keep under ~50 lines.
- `REPOSITORY.md`: lasting repository context, model distinctions, and run caveats. Read at the start of each task; update when these facts change.
- `EXPERIMENTS.md`: append one entry per experiment (template at top). Never rewrite old entries.
- `decisions/`: one short file per decision and its reason.
- `SERVERS.md`: hosts, envs, data paths.
- `supervisor/`: supervisor messages and ideas.
- `archive/`: old material. Read only when needed.

Rules: be terse, no padding, link to `results/` instead of copying data.
